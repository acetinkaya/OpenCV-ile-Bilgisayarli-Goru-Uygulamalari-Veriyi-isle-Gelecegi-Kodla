İlim Yayma Cemiyeti & Alaca Teknoloji Takımı iş birliğiyle İYC Tech Workshop Series kapsamında Görüntü İşleme Workshop’u, katılımcılara bilgisayarlı görünün temellerinden gerçek dünya uygulamalarına uzanan uygulamalı bir öğrenme deneyimi sunuyor.   

Bugün otonom araçlardan akıllı şehir sistemlerine, güvenlik kameralarından insansız hava araçlarına kadar pek çok teknoloji görüntüyü “anlayabilen” algoritmalar üzerine kurulmuştur.  
Bu programda katılımcılar Python ve OpenCV kullanarak görüntü ve videoları işlemeyi, nesneleri tespit edip takip etmeyi ve yapay zeka modellerini gerçek senaryolara uygulamayı adım adım öğreneceklerdir.   

Eğitimin İçeriği & Projeler:

* Python & Görüntü İşleme Temelleri   
* Resim, Video ve Kamera Görüntü Analizi   
* Yapay Zeka (AI) Uygulamaları   
* Gelişmiş Görüntü İşleme Uygulamaları   
* İHA Tabanlı Gemi Takibi   
* YOLOv8 ile Canlı Trafik Analizi  
* ROI ile Şerit Yoğunluk Analizi

# Kurulum Detayları

1. İlk Ekran Geldikten Sonra: Ana Ekranda Klavyeden "Ctrl + Shift + P" tuşlarına aynı anda basıp gelen menuden "Configure Display Language" Türkçe Dil Paketi yüklenebilir. Yazılımın orjinali İngilizce dil paketlidir.

2. Tema Rengini değiştirmek istiyorsakta aynı tuş kombinasyonundan "Tema" Rengi bölümüne gidilerek değişiklikler istege göre yapılabilir.

3. Harddiskin bölümünde "Goruntu_Isleme_Dersleri" isimli bir klasör oluşturun.

4. Dosya menusunden "Klasor Ac" diyerek ilgili klasörün yüklendiği kısma ulasırız. Klasor yolu seciminden VS Code size bu dosyada uyarı verecektir. O kısımda bu dosyaya güven diye seciniz.

5. VS Code ana ekranından uzantılar kısmından "python" yazılarak eklenti yüklenmelidir. python kurulumu yaparken aşağıdaki ekran gelmektedir. Onayınız ile işlemlere devam ediniz. 

![alternatif metin](https://github.com/acetinkaya/OpenCV-ile-Bilgisayarli-Goru-Uygulamalari-Veriyi-isle-Gelecegi-Kodla/blob/main/python-uv.png)

6. VS Code Terminal Menüsünden "Yeni Terminal" diyerek kurulumlara devam ediyorz.

7. İlk defa sanal ortam oluşturmak için (.venv), gelen terminal ekranına "uv venv" yazılmalıdır. Bu işlemde hata alınması normaldir. VS Code'yi kapatıp yeniden çalıştırın.

8. Tekrar VS Code çalıştırıldığında "uv venv" yazın ve aşağıdaki çıktıyı elde etmiş olacağız.
